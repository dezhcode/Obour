۱. **SETUP_FA.md** ← اول این را بخوان. راه اندازی قدم به قدم با مقادیر پنل خودت.
۲. **UI_FA.md** ← رابط کاربری و بخش های ربات

۴. **CHANGES_V17_FA.md** ← تغییرات نسخه ۱۷ (امنیت و مالی) و فایل هایی که باید جایگزین شوند
۵. **CHANGES_FA.md** ← تغییرات نسبت به نسخه اولیه

## راه اندازی سریع

```bash
pip install -r requirements.txt
cp .env.example .env
nano .env          # مقادیر را پر کن (مخصوصا PANEL_PASSWORD)
chmod 600 .env
python seed_plans.py
python main.py
```

## ساختار پروژه

```
app/
  config.py       تنظیمات از فایل env
  db.py           لایه دیتابیس SQLite
  panel.py        لایه اتصال به پنل PasarGuard
  texts.py        همه متن های ربات (لحن برند عبور)
  keyboards.py    همه دکمه ها
  utils.py        ابزارها (QR، قیمت گذاری، نوار مصرف)
  middlewares.py  ثبت کاربر، رفرال، محدودیت نرخ
  states.py       وضعیت های FSM
  handlers/
    start.py      شروع، منوی اصلی، پشتیبانی
    buy.py        خرید پلن آماده + پیشنهاد ارتقا
    extras.py     تست رایگان، ساخت دلخواه، راهنما، هم سفرها
    wallet.py     کیف پول و شارژ کارت به کارت
    services.py   سرویس های من و تمدید
    admin.py      پنل ادمین
main.py           راه اندازی (polling یا webhook)
seed_plans.py     درج پلن های اولیه
```

## نکات کلیدی

### بدون نیاز به User Template
همه سرویس ها (پلن آماده، تست رایگان، ساخت دلخواه) مستقیم با
`create_service()` روی پنل ساخته می شوند. تنها پیش نیاز `PANEL_GROUP_ID`
است که با مقدار `all` همه گروه های پنل را خودکار پیدا می کند.

### امنیت مالی
- کسر اتمیک: موجودی هرگز منفی نمی شود
- قفل عملیات در دیتابیس: هر کاربر در هر لحظه یک خرید/تمدید
- تراکنش ناموفق پاک نمی شود، با وضعیت failed و دلیلش می ماند
- تفکیک خطای امن از مبهم: اگر پاسخ پنل گم شود، قبل از بازگشت پول
  وضعیت واقعی از پنل تایید می شود

### تست شده
- منطق مالی با دیتابیس واقعی SQLite (۴ سناریو بحرانی)
- طبقه بندی خطای پنل (۸ حالت)
- محاسبه قیمت گذاری پلکانی
- یکپارچگی متن ها و دکمه ها (۵۷ متن، ۵۹ دکمه، بدون یتیم)

### تست نشده (باید خودت انجام دهی)
- اتصال واقعی به پنل
- صفر شدن مصرف موقع تمدید
- رندر دکمه ها در تلگرام
