# آیکن های AsoTas

آیکن های بازی و دکمه ها اینجا می آیند (فایل SVG).

## اضافه کردن آیکن تازه
1. فایل SVG را در همین پوشه بگذار؛ اسم کوتاه انگلیسی با خط تیره، مثل `nav-games.svg`.
2. در `static/gc.js` در `ICON_FILES` یک خط اضافه کن: `کلید: 'static/icons/اسم-فایل.svg'`.

رنگ فایل مهم نیست: آیکن به شکل ماسک کشیده می شود و رنگش را از جای خودش می گیرد
(مثلا روی دکمهٔ طلایی وسط نوار پایین، تیره). بهتر است `viewBox` مربعی داشته باشد (مثل `0 0 24 24`).

## آیکن های فعلی
| فایل | کجا |
|---|---|
