# ربات عبور (Obour) — فاز ۱

ربات فروش کانفیگ روی پنل PasarGuard — طبق سند `Obour_Bot_Spec.md`.

## چه چیزهایی ساخته شده (فاز ۱)

- ثبت کاربر با آیدی عددی تلگرام + deep link رفرال (زیرساخت)
- منوی اصلی با لحن برند
- **خرید سرویس** با ترتیب امن: ساخت روی پنل ← کسر اتمیک موجودی ← تحویل لینک + QR
- **Idempotency از فاز ۱**: قفل ضدتکرار روی خرید و تمدید (دابل کلیک = یک خرید)
- **کیف پول + شارژ کارت‌به‌کارت** با تأیید دستی ادمین (تایید/رد با دلایل آماده/رسید تکراری)
- **سرویس‌های من**: مصرف زنده از پنل + نوار پیشرفت + QR + تمدید همان اکانت (لینک ساب ثابت)
- **پنل ادمین**: داشبورد، شارژهای در انتظار، مدیریت کاربر (شارژ دستی، مسدودی)، مدیریت پلن‌ها (قیمت، Template، فعال/غیرفعال)، تنظیمات کارت (بدون ری‌استارت)، پیام همگانی (با تاخیر ضدبلاک)
- **پشتیبانی**: پیام کاربر فوروارد به ادمین‌ها؛ ادمین با Reply جواب می‌دهد
- حالت اجرا: Polling (تست) و Webhook (پروداکشن با `secret_token`)

## راه‌اندازی سریع

```bash
pip install -r requirements.txt
copy .env.example .env      # و مقادیر را پر کن
python seed_plans.py        # درج ۶ پلن سند
python main.py              # حالت polling برای تست
```

### تنظیمات .env

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن BotFather |
| `ADMIN_IDS` | آیدی عددی مدیرها با کاما |
| `PANEL_BASE_URL` | آدرس پنل PasarGuard |
| `PANEL_API_KEY` | API Key با دسترسی محدود (ساخت/خواندن/ویرایش کاربر + آمار) |
| `WEBHOOK_MODE` | `true` فقط روی سرور با HTTPS |

### آماده‌سازی پنل (یک‌بار — بخش ۴ سند)

۱. ساخت Group با inboundهای خوب
۲. ساخت User Template برای هر پلن (حجم بر حسب بایت، مدت بر حسب روز)
۳. ساخت API Key با Custom permissions
۴. از پنل ادمین ربات: مدیریت پلن‌ها → هر پلن → «تغییر Template» → آیدی تمپلیت را وارد کن
۵. تنظیمات → شماره کارت، صاحب کارت، بانک را وارد کن

## معماری

```
main.py            نقطه ورود (polling / webhook)
app/config.py      تنظیمات env
app/db.py          SQLite (WAL) + عملیات مالی اتمیک + idempotency
app/panel.py       لایه PasarGuard (کتابخانه رسمی pasarguard، API Key)
app/texts.py       پیام‌های برند (بخش ۱۳ و ۱۴ سند)
app/keyboards.py   کیبوردها
app/middlewares.py ثبت کاربر + مسدودی + ضداسپم
app/handlers/      start / buy / wallet / services / admin
seed_plans.py      درج پلن‌ها
```

## نکات امنیتی رعایت‌شده

- توکن‌ها فقط در `.env` (در `.gitignore`)
- کسر/شارژ موجودی اتمیک (`UPDATE ... WHERE balance >= ?`)
- تایید/رد شارژ فقط یک‌بار قابل انجام (اتمیک از وضعیت pending)
- غیرادمین‌ها پاسخ نمی‌گیرند؛ کاربر مسدود شده قفل می‌شود
- وبهوک با `X-Telegram-Bot-Api-Secret-Token` تأیید می‌شود
- timezone همه timestamp ها: `Asia/Tehran`
